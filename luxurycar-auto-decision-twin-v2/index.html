Inventory Merchandising Operating System

This follows the operating pattern used by global dealership-merchandising platforms: one repeatable capture process per vehicle, then reuse the media package everywhere. We are adapting the model for Saudi luxury/import sellers; we are not copying another vendor's interface.

3D removed as a default requirement
ONE OPERATING LOOP

The owner only needs to understand four steps.

No feature maze
01

Add the vehicle

Use existing stock data or the current public listing. One vehicle gets one inventory record.

02

Guided phone capture

Staff follows the same exterior, interior, feature and condition shot sequence every time.

03

Build one media pack

Photos, real spin when enough footage exists, feature chapters, condition evidence and bilingual copy.

04

Publish and measure

Reuse the same approved assets on the vehicle page, social, WhatsApp and marketplace-ready exports.

Why this scales: the workflow repeats; the car changes. There is no custom 3D modelling project for every VIN.
